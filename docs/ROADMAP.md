# SpiderChat Roadmap

## Completed (v1.0)
- [x] Basic Next.js App Router setup
- [x] Express + Socket.IO Backend
- [x] Anonymous Chat Rooms (URL based joining)
- [x] Comic-book style UI/UX

## Current (v1.5) - "The Multiverse Expansion"
- [x] Prisma + PostgreSQL Database Integration
- [x] User Authentication (JWT)
- [x] Dashboard UI
- [x] Direct Messaging
- [x] Friend Requests & Management
- [x] Real-time Online Presence
- [x] Message Reactions & Editing
- [x] Socket Token Fallback for Cross-Origin

- [ ] Image & File Uploads (AWS S3)

- [ ] Push Notifications (PWA Support)
- [ ] End-to-End Encryption
