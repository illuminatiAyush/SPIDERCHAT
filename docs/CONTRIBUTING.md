# Contributing to SpiderChat

First of all, thank you for your interest in contributing to the multiverse! SpiderChat is an open-source project and we welcome contributions of all kinds: bug reports, feature requests, documentation improvements, and code.

## Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork** locally: `git clone https://github.com/your-username/SpiderChat.git`
3. **Install dependencies** in the root, `client`, and `server` directories.
4. **Setup environment variables** using `.env.example` files as templates.
5. **Run the app locally** using `npm run dev` in both `client` and `server`.

## Branching Strategy
- `main` is the production branch.
- Create feature branches off `main` like `feature/new-spider-suit` or `bugfix/web-shooters`.

## Pull Requests
- Keep PRs focused on a single issue.
- Ensure your code follows the existing style (Tailwind classes, component structure).
- Verify the build succeeds (`npm run build`) before submitting.
- Add screenshots for UI changes.

## Code of Conduct
Please be respectful to other contributors. We are all web-slinging in the same multiverse. Harassment or toxic behavior will result in a ban.
